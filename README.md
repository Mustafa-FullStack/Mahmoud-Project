🎨 Mahmoud Project - Modern Web Design
🌟 Overview
This project is a high-end web design created for Mahmoud. It focuses on a seamless user experience (UX) and a modern visual identity (UI).

🚀 Features
Responsive Design: Works perfectly on mobile, tablet, and desktop.

Modern UI: Clean layouts with high attention to typography and spacing.

Performance: Optimized assets for fast loading times.

Interactive Elements: Smooth transitions and hover effects.

🛠️ Tech Stack
Design: Figma / Adobe XD

Frontend: HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)

Frameworks: (مثلاً Bootstrap أو Tailwind لو استخدمتهم)
